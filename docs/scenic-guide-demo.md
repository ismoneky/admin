# 景区导览本地演示

无需启动 Nest、登录后台或配置腾讯云环境变量。

```sh
cd admin
npm run dev:guide-demo
```

使用 Node 20.19+ 或 22.12+，浏览器打开 http://127.0.0.1:4319/scenic-guide 。

页面使用与正式后台相同的导览编辑器，预置原始导览图和五个示例地点。

1. 选择左侧地点，修改名称、分类、简介、排序或显示状态。
2. 拖动图上的数字标记；也可以点击“重新选点”后在图上指定位置。
3. 点击“新增”，在底图上点击位置，再填写地点名称。
4. 点击“保存并更新”，刷新页面验证保存结果。
5. “上传底图 / 配图”会把图片放在本地开发服务的内存中，模拟正式版选图；支持 JPG、PNG、WebP，每张最大10 MB，总计最多50 MB。
6. “恢复示例”会清除演示改动和图片。

演示数据只保存在开发服务内存中：刷新页面保留，重启服务恢复初始示例。多人或多个标签页共用同一服务的数据，保存版本冲突时需重新加载。可用“导出配置”留存文字与位置，但演示图片地址不会在正式环境生效。

`guide-demo` 仅在 Vite 开发模式启用。演示模式关闭线上 API 代理并拦截未开放接口，不会更新线上小程序或 COS。普通 `npm run dev` 和生产构建仍使用正式登录及接口；正式图片仍是腾讯云 COS 浏览器直传。
